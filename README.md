* **시험 시간:** 50분
* **진행 방식:** 오픈북 (공식 문서, 오프라인 개인 학습 자료 검색 가능 / 인터넷 검색 불가 / AI 코드 생성 도구 사용 금지)
* **제출물:** 
  1. 본인이 작업한 **Private GitHub 저장소 링크** (교사 계정 Collaborator 초대 필수)
  2. 시험 시작부터 최종 Push까지 전 과정이 녹화된 **OBS 화면 녹화 영상**

## 1. 시작하기 (저장소 생성 및 로컬 환경 설정)

1. 우측 상단의 초록색 **`[Use this template]` → `[Create a new repository]`** 버튼을 클릭합니다.
2. 저장소 이름(Repository name)을 **`학번_이름_mpg`** (예: `2101_홍길동_mpg`) 형식으로 입력하고, 반드시 **`Private`**을 선택하여 생성합니다.
3. 생성된 본인 저장소의 **`Settings` → `Collaborators`**에서 담당 교사 GitHub ID(`@교사아이디`)를 초대합니다.
4. 본인 PC의 로컬 IDE(VS Code, PyCharm 등)에서 저장소를 클론합니다.
   ```bash
   git clone [https://github.com/본인아이디/학번_이름_mpg.git](https://github.com/본인아이디/학번_이름_mpg.git)
